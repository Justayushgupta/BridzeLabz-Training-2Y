# BridzeLabz-Training-2Y

A collection of Java programming exercises and assignments completed as part of the BridzeLabz training program. This repository serves as a personal practice log covering core data structures and problem-solving concepts in Java.

## 📁 Repository Structure

```
BridzeLabz-Training-2Y/
├── Arrays/               # Array-based problems and solutions
├── Strings/              # String manipulation exercises
├── linkedlist/           # Linked list implementations and problems
├── assignement_1221.zip  # Assignment submission archive
└── README.md
```

## 📌 Topics Covered

- **Arrays** – Searching, sorting, and manipulation problems using Java arrays.
- **Strings** – Common string handling and manipulation exercises.
- **Linked List** – Custom implementations and operations on linked list data structures.

## 🛠️ Tech Stack

- **Language:** Java
- **Build/Run:** Any standard Java IDE (IntelliJ IDEA, Eclipse) or `javac`/`java` from the command line.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Justayushgupta/BridzeLabz-Training-2Y.git
   ```
2. Navigate into a topic folder (e.g., `Arrays`, `Strings`, `linkedlist`).
3. Compile and run the desired Java file:
   ```bash
   javac FileName.java
   java FileName
   ```
